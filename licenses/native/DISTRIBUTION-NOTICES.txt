Bundled Apache Subversion CLI for Windows

ProbeLoom invokes the bundled svn.exe / svnmucc.exe as independent processes.
The Apache-2.0 application license does not replace any third-party license.
The selected executable/DLL files come from official MSYS2 packages. Serf is
rebuilt with the enclosed Apache-2.0 empty-peek patch; all other selected files
are unmodified.
Exact versions, source inputs, package provenance, and hashes are recorded in
dependencies.json. Original notices and complete corresponding sources are
provided under msys2/. SOURCE-BUILD.md gives build and replacement instructions.

Selected-library license summary (the complete source packages contain other
utilities/documentation under additional licenses; they are not runtime EXEs):
- Apache Subversion, APR, APR-util, Serf, OpenSSL: Apache-2.0; their complete
  notices also describe embedded permissive components. Subversion includes
  utf8proc 2.1.0 (MIT and Unicode terms), fully covered by its bundled notices.
- MSYS2 runtime DLL: LGPL-3.0-or-later with the linking exception in
  winsup/CYGWIN_LICENSE, plus BSD/Newlib component terms in COPYING.NEWLIB.
- libgcc: GPL-3.0-or-later WITH GCC-exception-3.1; COPYING.RUNTIME is preserved.
- libxcrypt, libiconv and libintl: LGPL; exact version terms in their sources.
- LZ4 library: BSD-2-Clause; libuuid: BSD-3-Clause; liblzma: 0BSD.
- libexpat: MIT; file/libmagic: BSD-2-Clause and retained source-file notices.
- SQLite: public domain dedication; zlib: Zlib; Zstandard: BSD-3-Clause;
  bzip2: bzip2 license; Cyrus SASL: its original Cyrus SASL license.

Redistribute this entire legal/source directory with the selected binary
components. Preserve original copyright, license, exception and notice texts.
LGPL libraries remain separate replaceable DLLs. Users may modify/rebuild and
replace them; reverse engineering to debug those modifications is permitted.
No restrictions added by ProbeLoom override those component permissions.
Refer to the original texts for the complete conditions. Source package build
recipes, patches and auxiliary inputs accompany each matching source version.
GCC and OpenSSL sources are split into <=40 MiB fragments; reassembly verifies
each complete original archive hash.
